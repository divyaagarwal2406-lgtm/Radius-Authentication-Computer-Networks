# External Authentication Using RADIUS

## Project Overview
This Computer Networks project demonstrates centralized user authentication using FreeRADIUS on Ubuntu Linux.

## Objectives
- Install and configure the FreeRADIUS server.
- Configure RADIUS clients.
- Test authentication using the `radtest` command.
- Study Access-Accept, Access-Reject, and No Reply responses.
- Understand password storage and hashing concepts.

## Technologies Used
- Ubuntu Linux
- FreeRADIUS
- Oracle VirtualBox
- RADIUS protocol
- Linux terminal commands

## Project Contents
- RADIUS authentication report
- System architecture
- Server and client configuration
- Authentication test cases
- Password hashing discussion

## How to Test
Follow the setup instructions in the report to configure FreeRADIUS and test authentication using `radtest`.

## Result
The project demonstrates the working of centralized authentication using the RADIUS protocol.
